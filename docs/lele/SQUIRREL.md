## 素材与实现

- 固件图片：main/boards/lckfb/szpi-esp32s3/assets/squirrel/，7 张 259×259 RGBA PNG，
  共 355,269 bytes（约 347 KiB）。使用共同裁剪范围、等比例缩小及透明补边，
  不对各表情单独放大，减少状态切换时的尺寸/位置跳动。
- 原始编辑提示词保存在同目录 PROMPTS.md，母版提示词在 MASTER_PROMPT.md。
  七张 1448×1086 原图现在保存在同目录 originals/（约 6.8 MiB），不嵌入固件。
  用 scripts/lele/prepare_squirrel.py 从原图直接生成运行资源；依赖固定在
  requirements-artwork.txt。--check 可核对重制结果，不需要图像生成工具。
- main/CMakeLists.txt 仅在启用该 UI 时把 PNG 嵌入应用 Flash，不依赖 SD 或下载。
  squirrel_images.* 提供生命周期稳定的 LVGL 描述符；不改变原资源分区内容。
- lele_display.h 在原 SpiLcdDisplay 上接入表情/状态替换；沿用原布局、主题、
  预览图、字幕、横竖屏和触摸区域，不创建新的音频或网络流程。
  同一表情重复请求不会重复设置图片源。
- PNG 由现有 LodePNG 解码器处理；每张 259×259 RGBA 像素约 262 KiB，此外
  还有 PNG 解码临时内存及 LVGL 开销。目标已配置 1 MiB LVGL 内存池，图片缓存
  为零；不能把文件压缩大小当作运行内存，也不预先把七张原图展开常驻。

### 1.8 倍裁剪修复（5274748 已刷入，基本构图通过）

54b53009b4ad 实机被原方形区域裁剪，E-01 失败。当前 LVGL lv_obj_redraw
先把绘制 clip 缩至父对象 coords + ext_draw_size；overflow-visible 并不会
自动扩大这个透明父对象的 ext_draw_size，因此旧方案仍裁成 144px 方框。
新 squirrel_layout.h 将透明 emoji_box 设为视口百分比 100%×100%，禁用
其滚动，原图保持居中及 scale 461。父容器跟随方向变化，不改变相机预览
显隐关系和顶部状态/底部字幕层次。屏幕物理边界及字幕遮挡仍须上板验收。

真实 LVGL snapshot 对两方向分别渲染 144px 实色图：旧 overflow 方案在原
方框外像素为零，复现裁剪；新方案在方框外可见像素超过 20000。该检查验证
实际绘制而非仅检查配置值。表情方法回归也通过；不等同于实际松鼠构图验收。

5274748df928 已完整备份/校验后刷入，启动及 346 首缓存/扫描正常；用户确认
原方框裁剪消失、耳朵尾巴正常、横竖屏及字幕间距/1.8 倍大小合适。
七种情绪和预览/菜单组合未逐项验收，见 [版本记录](testing/test-5274748df928-01.md)。
