## 使用设计

长按功能键（BOOT）约 2 秒 → Songs。保留现有 USB File Transfer 和 Display 选项。
列表标题显示页数与总首数，每页五首，底部为 Prev / Next / Stop / Back。

- 轻点歌曲播放；正在播放另一首时可直接选择切换。语音监听/播报中选择歌曲，
  复用现有播放器结束语音通道后播放；启动/连接/升级等状态提示等待。
- 名称使用资源中已有的 common 中文字体；每行固定 30px，文字高度由单行字体决定，能放下的名称保持静止，超宽名称横向滚到末尾停 1 秒，再跳回开头重播，目录名作为后缀帮助区分重名。
- 长按歌曲只查看完整相对路径，在顶部标题栏滚动显示；不会同时触发播放。
- Stop 停止音乐；Back 回主菜单。物理键短按/长按关闭菜单也可，返回不自动停止音乐。
- 采用分页，不支持整表拖动滚动；拖动歌曲行不应点播。助手全屏轻点在列表打开时被隔离。
- 不增加新的云端工具；语音唤醒保持现有功能，语音工具和本地列表沿用同一个播放请求管线。

## 数据与资源

GetLichuangMusicPage 在现有 card_mutex 下复制当前页五个路径及状态、revision，
释放锁后才构建 LVGL，不读文件、不触发扫描。每页最多五条 240-byte 路径；
固定九个按钮上下文，避免为 1024 首创建全部控件或复制整个 PSRAM 曲库。
已有中文字体从 Theme::GetTextFont 获取并持有 shared_ptr，不新增字体/模型包；
字体覆盖范围仍为现有 common 字符集，少见字待实机检查。

缓存加载和扫描发布索引时递增 RAM revision；打开页面每秒检查一次，变化后
保留可用页码、缩短曲库时夹到最后一页。旧索引刷新中仍可浏览，不等待整卡扫描。
空库、未就绪、扫描中、截断、索引警告与不可用状态有提示，首尾页禁用越界翻页。

歌曲按钮在 LVGL 回调中复制其绑定的完整路径到一个待处理请求；主任务取出后
重新检查存储门禁、ready、MP3 安全路径与当前索引成员，再调用 RequestMusic。
即使刷新使同编号换成另一首，也不能用旧编号播放新歌曲。扫描期间页面重建
不修改已经捕获的路径；被移除的路径提示重新选择。按路径快照选择不等于保证
文件仍可解码，实际播放失败沿用解码器错误与 MusicStatus 反馈。

锁顺序：先取 RAM 快照并释放 card_mutex，再取 LVGL 锁；触摸回调不访问文件、
音频或 card_mutex。播放和停止通过现有应用主任务排队，不创建额外音频管线。
不再保留独立状态/操作提示行；状态及长按详情与页数共用顶部单行标题栏。
五个歌名使用固定裁剪视口和完整单行标签；只在文字像素宽度超过视口时启动
单向动画，终点是文字宽度减去视口宽度。末尾停 1 秒后跳回，不换行、不首尾
拼接、不使用省略号。视口不接收点击，触摸仍由歌曲行按钮处理。

## 验证与边界

主机回归覆盖空库、1024 首分页、末页/越界页夹取、索引换表、旧路径拒绝、
存储门禁、错误状态、中文名称与同名目录。真实 LVGL 验证五行/四个控制按钮
在 320×240 内可见、可以命中，保留原全屏触摸层及菜单隔离回归。

基本实机交互已获用户确认：中文显示、翻页、轻点播放、停止、长按完整路径均正常。
未逐项验收：长名称/罕见字、连续切歌、返回时继续播放、索引更新期间点击、
坏文件错误反馈、语音与助手全屏触摸隔离、浅/深色。启动后扫描完成时
剩余 PSRAM 1094920 bytes，最大连续块 983040 bytes。
构建通过不等于实机验收。烧录需用户当次确认及完整 16 MiB 备份校验。

本轮主机验证额外覆盖：两种方向与普通/高行高字体；动画中间位置、末尾完整
露出、末尾 999ms 内保持、1000ms 跳回开头；长→短删除动画；同一歌名在
窄视口滚动、宽视口静止、再缩窄重新计算终点；五行及页脚可见/点击仍通过。
这是无实体屏幕的 LVGL 回归，不替代实际滚动观感、字体或音频并发验收。
