## Mac 端下载与核对

发布后使用下面明确标签和文件名；在仓库根目录执行，先保留本地改动并同步
main 获取本记录。若下载失败、摘要不符或五文件缺失，停止烧录。

```bash
gh release download test-039cf7b50d51-01 \
  --repo Leooon726/xiaozhi-lele-esp32s3 \
  --pattern 'lele-039cf7b50d51-01.zip' \
  --pattern 'lele-039cf7b50d51-01.zip.sha256' \
  --dir .local/firmware/test-039cf7b50d51-01
```

```bash
cd .local/firmware/test-039cf7b50d51-01
shasum -a 256 -c lele-039cf7b50d51-01.zip.sha256
python3 -m zipfile -e lele-039cf7b50d51-01.zip firmware
cd firmware
shasum -a 256 -c SHA256SUMS
```

全部核对后回到仓库根目录。Python 独立环境安装 `scripts/lele/requirements.txt`，
无需完整 ESP-IDF。使用 [BUILD_FLASH.md](../BUILD_FLASH.md) 的 canonical
`device.py flash --build <解压后firmware的绝对路径> --confirm-write`，多板时
明确 `--port`。必须先获得用户当次授权，由脚本完整备份和设备端校验 16 MiB，
核对分区表后五文件写入、校验 NVS。分区表不匹配时停止，不强制擦除。
本次发布授权不是设备烧录授权，原始备份和日志仅保存在本机 `.local/`。
