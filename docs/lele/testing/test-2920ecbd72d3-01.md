## Mac 下载与烧录

先保留本地改动、同步 main，阅读 AGENTS.md、AGENT_WORKFLOW.md 和本记录。
下载明确标签，不用 latest；旧版 8 位码不能用于本版。

~~~bash
gh release download test-2920ecbd72d3-01 \
  --repo Leooon726/xiaozhi-lele-esp32s3 \
  --pattern 'lele-2920ecbd72d3-01.zip' \
  --pattern 'lele-2920ecbd72d3-01.zip.sha256' \
  --dir .local/firmware/test-2920ecbd72d3-01
cd .local/firmware/test-2920ecbd72d3-01
shasum -a 256 -c lele-2920ecbd72d3-01.zip.sha256
python3 -m zipfile -e lele-2920ecbd72d3-01.zip firmware
cd firmware
shasum -a 256 -c SHA256SUMS
~~~

核对后回仓库根目录，Python 独立环境安装 scripts/lele/requirements.txt，无需
完整 ESP-IDF。取得当次烧录授权后，按 BUILD_FLASH.md 执行
`python scripts/lele/device.py flash --build <firmware绝对路径> --confirm-write`。
多板指定 --port。先完整备份并设备端校验 16 MiB，核对分区，写五文件保留 NVS；
不匹配则停止，不整片擦除。本次发布不是烧录或回滚授权。日志、备份、实际
歌名、路径清单、配对码只留本机 .local/。
