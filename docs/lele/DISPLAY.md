# 屏幕配色、亮度与方向

## 横竖屏切换（2026-11-20，源码已实现，尚未实机测试）

功能编号 F-008，当前默认 LVGL 助手界面的两个音乐变体支持：长按功能键约
2 秒 → Display → `Orientation: Landscape / Portrait`，点击即时切换，无需重启。
横屏为 320×240，竖屏为 240×320（相对原横屏旋转 90°）；不是重力感应自动旋转，
也不替换已有长按菜单行为。普通非音乐变体和 WeChat/Emote 界面暂不提供此入口。

默认横屏；选择写入 NVS `display/portrait`（0 横屏、1 竖屏），其他值按横屏
恢复。启动时在助手 UI、触摸绑定和 USB 传输界面构建前恢复方向，因此独立
USB 传输启动也沿用选择。旧配色、亮度和 USB 启动模式的键不变。

助手背景、状态栏、字幕宽度按屏幕适配；全屏点击区域继续使用百分比尺寸。
切换只改变显示/布局，不重建音频、音乐服务，不删除字幕或重启会话。
正在显示的相机预览按新宽度重新缩放。是否完全无闪烁需实机观察。

Songs 保持每页五首及原分页/按路径点播逻辑：竖屏按钮变窄，超长歌名继续
单行横向滚动，Prev/Next/Stop/Back 在底部完整可见；不因方向切换改变页大小。
Display 中亮度控件改为同排 `Dim -` / `Bright +`，为方向按钮腾出空间，
避免横屏高度不足导致 Back 被挤出。显示设置百分比仍在标题下方。

实现限于板级 `lele_display.h` / `lele_display_layout.h`、板初始化和菜单。
使用现有 ESP LVGL port 的硬件旋转；FT5x06 保持原始横屏映射，由 LVGL 统一
旋转输入坐标，避免触摸双重旋转。主任务执行切换，LVGL 锁内重置本次输入，
等待松手；菜单重建取消助手手势。传输中不显示设置入口、不允许切换方向。
未修改共享显示代码、硬件引脚、分区或曲库格式。

## 使用

1. 正常助手模式长按功能键（BOOT）约 2 秒打开 Lele Menu。
2. 点 Display，点 Theme: Light / Theme: Dark 切换两种配色，按钮显示当前选择。
   Dark 使用现有黑底白字主题；菜单与传输界面跟随。图像、表情和告警沿用原样。
3. Brightness - / + 调整背光，显示目标百分比。每次通常变化 10 个百分点，
   到边界截为 5% 或 100%；下限保留可见背光。无自动亮度、无定时切换。
4. Back 回主菜单，再点 Back 回助手；功能键短按也可直接关闭菜单。

配色和亮度分别保存在现有 NVS display/theme、display/brightness；不改已有
启动默认值（没有设置时 Light、75%），也不改变用户已保存的设置。设置立即
保存，重启或退出文件传输后恢复。文件传输界面只提供 Return，不提供显示调节。

## 实现与边界

代码限于板级 lele_menu.* 和构造时传入 Display/Backlight 指针，不增加全局
主题配置，不修改其他板型。触摸回调只写原子动作，主任务轮询执行，LVGL 修改
使用锁；设置页有四个固定高度按钮，不创建曲库等大量对象。配色调用现有
Display::SetTheme 并持久化；亮度保存请求目标，避免把 PWM 渐变中间值保存。
到亮度边界继续点击不反复写入 NVS。

构造期间显式传入指针，传输启动也不递归调用 Board::GetInstance，不启动
摄像头/音乐/语音。传输准备中不能进入设置或切换页面；同一次启动内文件
所有权交接约束保持。原生 USB music-test 入口仍只在正常 debug 模式可用。
