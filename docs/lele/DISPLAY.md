## 使用

1. 正常助手模式长按功能键（BOOT）约 2 秒打开 Lele Menu。
2. 点 Display，点 Theme: Light / Theme: Dark 切换两种配色，按钮显示当前选择。
   Dark 使用现有黑底白字主题；菜单与传输界面跟随。图像、表情和告警沿用原样。
3. Brightness - / + 调整背光，显示目标百分比。每次通常变化 10 个百分点，
   到边界截为 5% 或 100%；下限保留可见背光。无自动亮度、无定时切换。
4. Back 回主菜单，再点 Back 回助手；功能键短按也可直接关闭菜单。

配色和亮度分别保存在现有 NVS display/theme、display/brightness；不改已有
启动默认值（没有设置时 Light、75%），也不改变用户已保存的设置。设置立即
保存，重启或退出文件传输后恢复。文件传输界面只提供 Return，不提供显示调节。

## 实现与边界

代码限于板级 lele_menu.* 和构造时传入 Display/Backlight 指针，不增加全局
主题配置，不修改其他板型。触摸回调只写原子动作，主任务轮询执行，LVGL 修改
使用锁；设置页有四个固定高度按钮，不创建曲库等大量对象。配色调用现有
Display::SetTheme 并持久化；亮度保存请求目标，避免把 PWM 渐变中间值保存。
到亮度边界继续点击不反复写入 NVS。

构造期间显式传入指针，传输启动也不递归调用 Board::GetInstance，不启动
摄像头/音乐/语音。传输准备中不能进入设置或切换页面；同一次启动内文件
所有权交接约束保持。原生 USB music-test 入口仍只在正常 debug 模式可用。
