- [ ] 点击屏幕上的助手区域，实现现有功能键的短按效果：待机时开始交互，交互中结束 / 回到待机。这里的“关闭”指结束交互，不是断电或永久禁用唤醒。
- [ ] 与现有功能键复用应用入口，经过主任务调度；明确按住说话模式下的行为。

- [ ] 实机验收待机、监听、回答等状态下的行为，确认触摸坐标、去抖和语音流程正常。

## 3. USB 连接 Mac 管理 SD 卡歌曲

目标：不拔 SD 卡，通过 USB 在 Mac 上添加歌曲、修改文件名，并使设备索引随后更新。

- [ ] 确认板上 USB 数据线路 / 接口与 USB-OTG 的可用性；当前 USB Serial/JTAG 调试口不等于 USB 磁盘。
- [ ] 优先评估 ESP-IDF 官方 TinyUSB MSC / SD 卡示例，使 SD 卡显示为 macOS Finder 可读写的磁盘；不从头实现 USB 存储协议。
- [ ] 设计显式“文件传输模式”：停止音乐、暂停扫描、关闭文件并卸载设备侧文件系统，再把 SD 卡交给电脑；不能让电脑和固件同时挂载写同一 FAT 文件系统。
- [ ] 电脑安全推出并退出传输模式后，设备重新挂载 SD 卡并刷新索引；覆盖改名、添加、删除和异常断线的恢复。
- [ ] 核对切换 USB 功能后现有 Serial/JTAG 调试与烧录路径的影响，保留可恢复流程；如需串口共存，单独评估 TinyUSB CDC 复合设备。
- [ ] 在 macOS 实测复制 MP3、中文改名、安全推出、恢复播放与语音；不得格式化现有 SD 卡或改动用户歌曲用于测试。

当前状态：源码已接入功能键长按 2 秒菜单及独立启动 USB MSC/SDMMC 模式，使用官方 esp_tinyusb；当前设备已刷入并正常启动；已进入传输模式，Mac 枚举和 340 首目录/缓存读取通过；当前卷只读，写入及退出仍待验收。复制/中文改名/安全推出/恢复/断线仍需实机验收，故上列验收项保持未勾选。见 [实现与操作说明](USB_TRANSFER.md)。
